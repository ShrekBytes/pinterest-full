# Changelog

- Batch download for multi-image story pins
- Toast notifications for user feedback
- Image metadata display (format and file size)
- Image counter in gallery header (e.g., "3 / 7")

### Improved

- Performance optimizations and code refactoring
- Better error handling and user messages
- Browser compatibility fixes
- Enhanced accessibility

### Fixed

- Duplicate button injection prevention
- API timeout handling for older browsers
